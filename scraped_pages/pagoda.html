14' x 14' Pagoda

This 14'x 14' pagoda provides a year-round sheltered outdoor space for cooking and relaxing. The hip roof is a beautiful complement to the roof line of the house. Integration with the existing structure involved careful design considerations and attention to detail. This project was built with well-seasoned wood which ensures tight joinery over time.
